# pyRouterJig
pyRouterJig is a woodworking layout tool for creating box and dovetail
joints.

For more information, [see the pyRouterJig website](http://lowrie.github.io/pyRouterJig/)

## Notes

- Template Stop Spacing is only calculated for basic setups that use the `Equal` spacing tab.
- If the active configuration uses the `Variable` or `Editor` spacing tabs, or if the B-board cuts require multiple router passes, pyRouterJig shows a manual setup message instead of a computed Template Stop Spacing value.
- For those unsupported configurations, use the diagram to manually set up the required cut locations.
